# 뉴스레터 DB Excel 매크로

완성 파일은 다음 6개 시트로 구성됩니다.

1. DB-사업안내형
2. DB-아카데미
3. DB-배너형
4. DB-알림톡
5. 뉴스레터 · 알림톡 게재 일정
6. 최종

사용자는 네 DB 시트에만 자료를 입력합니다. 달력과 최종 시트는 매크로가 자동으로 갱신합니다. CSV 추출 프로그램은 마지막의 `최종` 시트를 찾아 사용합니다.

## 처음 한 번 설치

1. `newsletter_upload_compact.xlsx`를 Excel에서 엽니다.
2. `다른 이름으로 저장`에서 `Excel 매크로 사용 통합 문서 (*.xlsm)`로 저장합니다.
3. `Alt+F11`을 눌러 VBA 편집기를 엽니다.
4. `파일 > 파일 가져오기`에서 `NewsletterParser_Windows.bas`를 가져옵니다.
5. 왼쪽의 `Microsoft Excel Objects`에서 아래 네 시트를 차례로 더블클릭합니다.
   - DB-사업안내형
   - DB-아카데미
   - DB-배너형
   - DB-알림톡
6. 각 시트 코드 창에 `worksheet_event_code.txt`의 코드를 똑같이 붙여넣습니다.
7. 저장하고 Excel을 닫았다가 다시 연 뒤 `콘텐츠 사용` 또는 `매크로 사용`을 누릅니다.

정상 입력 때는 완료 알림창이 뜨지 않습니다. 문제가 있을 때만 오류 메시지가 표시됩니다.

## 평소 입력 방법

### DB-사업안내형

지원요청 본문의 `1.`부터 마지막 URL까지 복사합니다. `DB-사업안내형` 시트의 맨 아래 빈 행 B열을 한 번 클릭하고 `Ctrl+V`로 붙여넣습니다.

자동 입력 항목:

- 사업명
- 사업기간
- 신청마감일
- 게재요청기간
- URL

지원요청 제목, 요청부서, 요청자, 비고는 필요한 경우 직접 입력합니다.

다음 발행일에 실을 수 있는 자료 중 신청마감일이 가까운 순으로 최대 8건이 구분선 위에 배치됩니다. 마감일이 같으면 먼저 등록한 자료가 우선입니다. 나머지는 구분선 아래에 계속 보관됩니다.

### DB-아카데미

아카데미 메일의 첫 `[월.일]` 줄부터 두 번째 발행일 묶음의 마지막 URL까지 한 번에 복사합니다. 메일 본문이 복사되지 않으면 `답장` 창을 연 뒤 복사합니다.

`DB-아카데미` 시트의 맨 아래 빈 행 B열을 한 번 클릭하고 `Ctrl+V`로 붙여넣습니다. `[10.20]`, `[10.23]`처럼 발행일별로 자동 구분하고 각 날짜의 최대 4건을 저장합니다. 오늘을 포함해 가장 가까운 발행일의 자료가 `최종` 시트에 들어갑니다.

### DB-배너형

지원요청 본문의 `1.`부터 마지막 URL까지 복사합니다. `DB-배너형` 시트의 맨 아래 빈 행 B열을 한 번 클릭하고 `Ctrl+V`로 붙여넣습니다.

배너 이미지는 원문 등록 후 같은 행의 D열을 선택하고 `Ctrl+V`로 붙여넣습니다. 다음 발행일의 선착순 최대 2건이 구분선 위에 배치되고, `최종` 시트의 배너 1과 배너 3에 들어갑니다. 배너 2는 해외정보팀 담당 영역이므로 바뀌지 않습니다.

### DB-알림톡

사업안내형과 같은 지원요청 원문을 복사합니다. `DB-알림톡` 시트의 맨 아래 빈 행 B열을 한 번 클릭하고 `Ctrl+V`로 붙여넣습니다. `희망 발송일`, `희망 발송기간`, `발송 희망일`, `알림톡 발송일`, `알림톡 발송 희망일`, `희망 게재기간` 표기를 인식합니다.

월요일과 수요일마다 최대 2건이 발송 대상으로 선정됩니다. 신청마감일이 가까운 순으로 구분선 위에 배치하고, 마감일이 같으면 먼저 등록한 자료가 우선입니다. 비고는 I열에 직접 입력할 수 있습니다. 노란색 시트 탭으로 다른 DB와 구분됩니다.

## 자동 처리

- 파일을 열 때 `최종` 시트와 달력을 자동 갱신합니다.
- DB의 자료를 지우거나 직접 수정하면 `최종` 시트와 아직 지나지 않은 달력 일정에도 즉시 반영됩니다.
- 이미 지난 주차의 달력 내용은 작업 이력으로 보존되며 DB에서 자료를 지워도 함께 삭제되지 않습니다.
- 사업기간 종료일, 신청마감일 또는 게재요청기간 종료일이 지난 사업안내 자료는 삭제합니다.
- 게재요청기간이 지난 배너 자료는 삭제합니다.
- 아카데미의 지난 발행일 자료는 삭제합니다.
- 화요일·금요일을 정기 발행일로 계산하며 등록된 공휴일은 건너뜁니다.
- 달력에는 알림톡, 사업안내형과 배너형을 표시합니다.
- 알림톡은 월·수에 최대 2건, 사업안내형과 배너형은 화·금에 각각 최대 8건과 2건을 기본 정원으로 표시합니다. 정원을 넘는 자료도 구분선 아래 행에 표시합니다.
- 달력 날짜는 `YYYY-MM-DD` 형식으로 표시하며 시간 문자열은 표시하지 않습니다.
- 파일을 열면 현재 주보다 이전인 모든 주차가 접힌 상태가 됩니다. 왼쪽의 `+` 버튼을 누르면 과거 주차를 다시 펼칠 수 있습니다.
- 필요할 때 `전체_새로고침` 매크로를 실행하면 최종 시트와 달력을 다시 계산합니다. 성공 알림은 표시하지 않고 오류가 있을 때만 알림창을 표시합니다.

## 날짜와 URL 처리

다음과 같은 날짜 표기를 처리합니다.

- 2026/10/31, 2026.10.31., 2026년 10월 31일
- 10.31, 10/31, 10.31.
- 10.26~10.28, 10.26-10.28
- 26.10.11~13
- ~10.28
- 2026.12.31~1.1
- 교육일이 여러 개인 `2026.11.20·11.27·12.4`

연도가 없으면 작업하는 컴퓨터의 현재 연도를 사용합니다. KOTRA 주소가 `https://kotra.or.kr/...`이면 `https://www.kotra.or.kr/...`로 자동 보정합니다.

모아폼, 구글폼, 네이버폼 URL은 행 전체를 연한 빨간색으로 표시하고 아래 경고를 붙입니다.

`00폼은 보안상 사용이 금지된 설문조사 플랫폼입니다. 지원요청자에게 KOTRA 내부 설문조사 플랫폼 등으로 URL 수정을 요청하세요.`

반출 후 인터넷망에서 모든 URL을 하나씩 직접 열어 내용이 맞는지 확인하고, KOTRA 페이지 안의 신청 버튼이 외부 설문조사 플랫폼으로 이어지는지도 반드시 확인하세요.

## 참고

- 시트 이름은 바꾸지 마세요.
- `최종` 시트의 표 위치와 모양은 CSV·Photoshop 자동화가 사용하므로 바꾸지 마세요.
- `NewsletterParser_Windows.bas`는 Windows VBA 편집기용 CP949 인코딩 파일입니다.
- 이 Mac 환경에서는 Windows Excel VBA의 실제 실행·컴파일까지 확인할 수 없으므로, 처음 설치한 뒤 샘플 1건으로 입력과 새로고침을 확인하세요.
