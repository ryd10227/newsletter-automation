# Excel 원문 파싱 매크로 - DB·달력 개편 전 버전

이 폴더는 `DB-사업안내형`, `DB-아카데미`, `DB-배너형`, `DB-알림톡`, 달력 시트를 추가하기 전의 단일 시트 버전입니다.

통합 문서에는 `최종 업로드` 시트 하나만 있습니다. 사업안내형·아카데미·배너형 원문을 각 구역의 연번 1 B열에 붙여넣으면 같은 시트 안에서 바로 정리합니다.

## 설치

1. `newsletter_upload_compact.xlsx`를 Excel에서 엽니다.
2. `다른 이름으로 저장`에서 `Excel 매크로 사용 통합 문서 (*.xlsm)`로 저장합니다.
3. `Alt+F11`을 눌러 VBA 편집기를 엽니다.
4. `파일 > 파일 가져오기`에서 `NewsletterParser_Windows.bas`를 가져옵니다.
5. `Microsoft Excel Objects > 최종 업로드`를 더블클릭합니다.
6. `worksheet_event_code.txt`의 코드를 시트 코드 창에 붙여넣습니다.
7. 저장한 뒤 Excel을 닫았다가 다시 열고 매크로 사용을 허용합니다.

## 입력

- 사업안내형: 지원요청 본문의 `1.`부터 마지막 URL까지 복사해 사업안내형 연번 1 B열에 붙여넣습니다.
- 아카데미: 해당 발행일 `[월.일]` 줄부터 네 번째 항목의 마지막 URL까지 복사해 아카데미 연번 1 B열에 붙여넣습니다.
- 배너형: 지원요청 본문의 `1.`부터 마지막 URL까지 복사해 배너형 연번 1 B열에 붙여넣습니다.
- 배너 이미지는 표 아래 칸에 배너 1, 배너 3 순서로 삽입합니다. 배너 2는 해외정보팀 담당 영역입니다.

날짜 형식 변환, `kotra.or.kr` 주소의 `www.` 보정, 모아폼·구글폼·네이버폼 경고 기능이 포함된 당시 버전입니다.

이 폴더의 파일은 개편 전 버전끼리만 함께 사용하세요. 현재 `0_excel_macro` 폴더의 파일과 섞지 마세요.
