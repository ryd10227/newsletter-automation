뉴스레터 작업 순서
==================

모든 날짜는 YYYYMMDD 8자리로 씁니다.
문서의 [발행일8자리]은 실제 발행일 8자리를 뜻합니다.
예: 2026년 10월 27일 → 20261027


입력 폴더
---------
work_history\[발행일8자리]\
└─ input\
   ├─ newsletter_DB_[발행일8자리].xlsm 또는 .xlsx  ← 작성 완료된 뉴스레터 데이터
   └─ [발행일8자리]_letter\                         ← 해외정보팀에서 전달받은 ZIP의 압축을 푼 폴더
      ├─ newsletter_[발행일8자리].psd               ← Photoshop 원본
      └─ newsletter_[발행일8자리].html              ← VDI 뉴스레터 HTML 원본

[발행일8자리]_letter 폴더에 다른 PNG·JPG 이미지가 있어도 자동화에서는 무시합니다.
Excel, 날짜 폴더, letter 폴더, PSD와 HTML의 날짜가 모두 같아야 합니다.


0. 입력 확인
-----------
1) 파일 탐색기에서 newsletter-automation 폴더를 엽니다.
2) run.cmd를 더블클릭합니다.
3) 검은 창에 작업할 발행일 8자리를 입력하고 Enter를 누릅니다.
   예: 20261027
4) Ready: [발행일8자리]이 나오면 입력 파일과 폴더 이름이 모두 정상입니다.
   오류 문구가 나오면 표시된 파일명이나 폴더명을 고친 뒤 다시 실행합니다.

PowerShell 창은 닫지 않습니다. 이후에는 같은 창에 1~4 숫자만 차례대로 입력합니다.


1. Excel → CSV
--------------
사용 파일: 1_excel_to_csv\export.py

입력
- newsletter_DB_[발행일8자리].xlsm 또는 .xlsx  ← 작성 완료된 Excel

출력
- output\newsletter.csv              ← 이후 자동화에 사용하는 중간파일
- output\images\banner_01.png        ← Excel에서 추출한 배너 1 이미지
- output\images\banner_03.png        ← Excel에서 추출한 배너 3 이미지

발행일은 Excel 파일명에서 자동으로 인식합니다.

실행 방법
PowerShell 창에 1을 입력하고 Enter를 누릅니다.

명령이 끝나면 output 폴더에 newsletter.csv가 생겼는지 확인합니다.


2. Photoshop
------------
사용 파일: 2_photoshop\fill.jsx

입력
- output\newsletter.csv                               ← 1단계에서 생성
- input\[발행일8자리]_letter\newsletter_[발행일8자리].psd       ← Photoshop 원본
- output\images\banner_01.png                         ← 배너 1 교체 이미지
- output\images\banner_03.png                         ← 배너 3 교체 이미지

출력
- output\newsletter_[발행일8자리].psd               ← 자동 입력된 결과 PSD
- output\images\bg.png                         ← 해외시장뉴스 메인 이미지
- output\images\banner_02.png                  ← 배너 2 이미지
- output\images\우측배너.png                   ← 경제외교 우측배너 이미지
- output\images\newsletter_[발행일8자리].png        ← 전체 뉴스레터 최종 이미지

실행 방법
1) PowerShell 창에 2를 입력하면 필요한 파일 경로가 표시됩니다.
2) Photoshop을 실행합니다.
3) 위쪽 메뉴에서 파일 → 스크립트 → 찾아보기를 누릅니다.
4) newsletter-automation\2_photoshop 폴더를 엽니다.
5) fill.jsx를 선택합니다.
6) 파일 선택창이 나오면 output\newsletter.csv를 선택합니다.
7) 다음 파일 선택창에서 input\[발행일8자리]_letter\newsletter_[발행일8자리].psd를 선택합니다.
8) 스크립트가 결과 PSD와 이미지들을 output 폴더에 자동 저장합니다.
9) 완료 안내가 나오면 결과를 확인하고 PowerShell 창으로 돌아갑니다.

3. VDI HTML + 무투24 HTML
-------------------------
사용 파일: 3_html\vdi.py, 3_html\mutu24.py
고정 템플릿: 3_html\mutu24_template.txt

입력
- output\newsletter.csv                                ← 1단계에서 생성
- input\[발행일8자리]_letter\newsletter_[발행일8자리].html       ← VDI HTML 원본
- output\newsletter_[발행일8자리].psd                       ← 2단계에서 생성

출력
- output\vdi_[발행일8자리].html                              ← 자동 입력된 VDI HTML
- output\mutu24_[발행일8자리].html                           ← 자동 입력된 무투24 HTML

실행 방법
PowerShell 창에 3을 입력하고 Enter를 누릅니다.

명령이 끝나면 output\vdi_[발행일8자리].html과 output\mutu24_[발행일8자리].html을 확인합니다.


4. 반입 ZIP 생성
----------------
사용 파일: 4_create_zip\create.py

입력
- output\images 안의 이미지 6개              ← 관리자페이지 업로드용 이미지
- output\vdi_[발행일8자리].html                    ← 3단계에서 생성
- output\mutu24_[발행일8자리].html                 ← 3단계에서 생성

출력
- output\[발행일8자리]_반입.zip                    ← 최종 반입용 압축파일

실행 방법
PowerShell 창에 4를 입력하고 Enter를 누릅니다.

명령이 끝나면 output\[발행일8자리]_반입.zip을 확인합니다.


최종 output
-----------
output\
├─ images\                                      ← 관리자페이지 업로드용 이미지
│  ├─ bg.png                                    ← 해외시장뉴스 메인 이미지
│  ├─ banner_01.png                             ← 배너 1
│  ├─ banner_02.png                             ← 배너 2
│  ├─ banner_03.png                             ← 배너 3
│  ├─ 우측배너.png                              ← 경제외교 우측배너
│  └─ newsletter_[발행일8자리].png                   ← 전체 뉴스레터 최종 이미지
├─ newsletter.csv                               ← 자동화 중간파일
├─ newsletter_[발행일8자리].psd                      ← 자동 입력된 결과 PSD
├─ vdi_[발행일8자리].html                            ← VDI 뉴스레터 HTML
├─ mutu24_[발행일8자리].html                         ← 무투24 HTML
└─ [발행일8자리]_반입.zip                            ← 최종 반입용 압축파일

ZIP에는 images 폴더와 HTML 2개만 들어갑니다.
CSV와 PSD는 작업용 중간파일이므로 ZIP에는 들어가지 않습니다.
