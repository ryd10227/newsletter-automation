뉴스레터 빠른 실행
==================

문서의 [발행일8자리]은 실제 발행일 8자리를 뜻합니다.
예: 2026년 10월 27일 → 20261027

시작 전 필수 준비
-----------------
run.cmd를 실행하기 전에 아래 폴더와 파일을 반드시 준비하세요.

work_history\
└─ [발행일8자리]\
   └─ input\
      ├─ newsletter_DB_[발행일8자리].xlsm 또는 .xlsx
      └─ [발행일8자리]_letter\
         ├─ newsletter_[발행일8자리].psd
         └─ newsletter_[발행일8자리].html

날짜 폴더, Excel, letter 폴더, PSD, HTML의 [발행일8자리]가 전부 같아야 합니다.
Excel 파일은 .xlsm 또는 .xlsx 중 하나만 넣으세요.

0. 실행
-------
1) newsletter-automation 폴더의 run.cmd를 더블클릭합니다.
2) 검은 창에 발행일 8자리를 입력하고 Enter를 누릅니다.
   예: 20261027

Ready: [발행일8자리]과 번호 메뉴가 나오면 준비가 끝난 것입니다.
이후에는 긴 명령을 복사하지 않고 숫자만 입력합니다. PowerShell 창은 닫지 않습니다.


1. Excel → CSV
--------------
PowerShell에 1을 입력하고 Enter를 누릅니다.


2. Photoshop
------------
1) PowerShell에 2를 입력하면 원본 PSD가 Photoshop으로 자동으로 열립니다.
2) Photoshop에서 파일 → 스크립트 → 찾아보기를 누릅니다.
3) 2_photoshop\fill.jsx를 선택합니다.
4) output\newsletter.csv를 선택합니다.
5) PSD 선택창에서 이미 열려 있는 input\[발행일8자리]_letter\newsletter_[발행일8자리].psd를 선택합니다.
6) 스크립트는 이미 열린 PSD를 재사용하므로 같은 파일을 중복으로 열지 않습니다.
7) 완료 안내가 나오면 결과를 확인하고 PowerShell 창으로 돌아갑니다.


3. VDI HTML + 무투24 HTML
-------------------------
PowerShell에 3을 입력하고 Enter를 누릅니다.
두 HTML이 차례대로 생성됩니다.


4. 반입 ZIP
-----------
PowerShell에 4를 입력하고 Enter를 누릅니다.


완료
----
output\[발행일8자리]_반입.zip이 생성됐는지 확인합니다.
