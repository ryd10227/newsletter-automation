# 뉴스레터 자동화 사용방법

Last Update 2026.11.01.  
by 윤서연

문서의 `[발행일8자리]`는 실제 발행일 8자리를 뜻합니다.  
예: 2026년 11월 3일 → `20261103`

## 1. 입력 파일 준비

```text
newsletter-automation\
├─ run.cmd
└─ work_history\
   └─ [발행일8자리]\
      └─ input\
         ├─ newsletter_DB_[발행일8자리].xlsm 또는 .xlsx
         └─ [발행일8자리]_letter\
            ├─ newsletter_[발행일8자리].psd
            └─ newsletter_[발행일8자리].html
```

발행일이 2026년 11월 3일이면 모든 날짜를 `20261103`으로 맞춥니다.  
Excel 파일은 `.xlsm` 또는 `.xlsx` 중 하나만 넣습니다.

## 2. 실행 순서 요약

```text
입력 파일 준비
→ run.cmd 더블클릭
→ 발행일 8자리 입력
→ 1 입력
→ 2 입력
→ 3 입력
→ 4 입력
→ 0 입력하여 종료
→ 생성된 output\[발행일8자리]_반입.zip 파일 반입
```

## 3. 실행

`run.cmd`를 더블클릭하고 발행일 8자리를 입력합니다.

```text
20261103
```

## 4. 번호별 진행

---

### 1단계: `1` 입력 — Excel → CSV

**사용자 작업**

PowerShell 창에 `1`을 입력하고 Enter를 누릅니다.

**자동 처리**

Excel의 최종 데이터를 읽어 CSV와 배너 이미지를 추출합니다.

**생성 파일**

```text
output\
├─ newsletter.csv
└─ images\
   ├─ banner_01.png
   └─ banner_03.png
```

**단계 종료 후 확인**

- [ ] `output\newsletter.csv`가 생성되었는지 확인
- [ ] CSV의 사업안내·아카데미·배너 제목, 기간, 마감일, URL이 Excel과 일치하는지 확인
- [ ] `banner_01.png`와 `banner_03.png`가 올바른 이미지인지 확인
- [ ] 경고가 표시됐다면 해당 행과 `image_path`를 반드시 확인

---

### 2단계: `2` 입력 — Photoshop 전체 자동화

**사용자 작업**

PowerShell 창에 `2`를 입력하고 작업이 끝날 때까지 기다립니다.

**자동 처리**

- Photoshop 실행
- 원본 PSD 열기 또는 기존 문서 재사용
- PSD 위치에서 `newsletter.csv` 자동 탐색
- `fill.jsx` 실행
- 텍스트와 배너 입력
- 결과 PSD 및 PNG 저장

**생성 파일**

```text
output\
├─ newsletter_[발행일8자리].psd
└─ images\
   ├─ bg.png
   ├─ banner_02.png
   ├─ 우측배너.png
   └─ newsletter_[발행일8자리].png
```

**참고**

오류나 경고가 있을 때만 다음 파일이 생성됩니다.

```text
output\photoshop_automation_error.log
```

**단계 종료 후 확인**

- [ ] 결과 PSD와 전체 PNG가 저장되었는지 확인
- [ ] 결과 PSD와 전체 PNG를 열어 배너 1·3의 모서리가 둥글게 잘렸는지 확인
- [ ] 배너 1·3이 기존 이미지에 가려지지 않고 올바른 이미지로 교체됐는지 확인
- [ ] 사업안내·아카데미의 제목, 기간, 신청마감 텍스트가 잘리지 않고 정확한지 확인
- [ ] `bg.png`가 해외시장뉴스 영역 상단 배너 전체인지 확인
- [ ] `bg.png`에 PSD에서 보이는 배경·오브제·텍스트가 전부 포함됐는지 확인
- [ ] `banner_02.png`, `우측배너.png`와 전체 뉴스레터 PNG가 정상인지 확인
- [ ] `photoshop_automation_error.log`가 있다면 내용을 확인하고 오류 해결

---

### 3단계: `3` 입력 — HTML 2개 생성

**사용자 작업**

PowerShell 창에 `3`을 입력하고 Enter를 누릅니다.

**자동 처리**

VDI HTML과 무투24 HTML을 차례대로 생성합니다.

**생성 파일**

```text
output\
├─ vdi_[발행일8자리].html
└─ mutu24_[발행일8자리].html
```

**단계 종료 후 확인**

- [ ] VDI HTML과 무투24 HTML을 각각 열어 확인
- [ ] 해외시장뉴스·사업안내·아카데미·배너·경제외교 등 모든 영역의 텍스트와 링크가 일치하는지 확인
- [ ] 링크 순서가 화면의 항목 순서와 정확히 일치하는지 확인
- [ ] 모든 URL을 하나씩 직접 열어 제목과 실제 연결 페이지 내용이 일치하는지 확인
- [ ] KOTRA 주소라도 페이지 안의 신청 버튼·연결 링크를 눌러 최종 목적지를 확인
- [ ] 본문과 연결 페이지에 네이버폼·구글폼·모아폼 이용을 유도하는 링크가 없는지 확인
- [ ] 본문과 이미지 안의 QR코드가 외부 설문조사 플랫폼으로 연결되지 않는지 확인
- [ ] 금지 플랫폼 발견 시 사용을 중단하고 지원요청자에게 KOTRA 내부 플랫폼 URL로 수정 요청

---

### 4단계: `4` 입력 — 반입 ZIP 생성

**사용자 작업**

PowerShell 창에 `4`를 입력하고 Enter를 누릅니다.

**자동 처리**

관리자페이지 업로드 이미지와 HTML 2개를 반입용 ZIP으로 묶습니다.

**생성 파일**

```text
output\[발행일8자리]_반입.zip
```

**단계 종료 후 확인**

- [ ] 반입 ZIP이 생성되었는지 확인
- [ ] ZIP 안에 `images` 폴더, VDI HTML, 무투24 HTML이 들어 있는지 확인
- [ ] 최종 검수가 끝난 파일만 외부메일로 반입

## 5. 종료

작업이 끝나면 `0`을 입력해 창을 종료합니다.  
생성된 `output\[발행일8자리]_반입.zip` 파일을 외부메일로 반입하여 사무실에서 작업을 이어갑니다.

## 6. CMD 화면에 표시되는 문구

### 실행 시작과 번호 메뉴

```text
Issue date (YYYYMMDD):
준비 완료: [발행일8자리]
입력 폴더: [input 전체 경로]
출력 폴더: [output 전체 경로]

============================================================
  뉴스레터 자동화: [발행일8자리]
============================================================
  1  Excel → CSV
  2  Photoshop 전체 자동화
  3  VDI HTML + 무투24 HTML
  4  반입 ZIP 생성
  0  종료
============================================================
번호 입력:
```

### 1단계 정상 완료

```text
시트: 최종
CSV: [newsletter.csv 전체 경로]
레코드: 사업안내 [개수], 아카데미 [개수], 배너 [개수]
배너 이미지: [개수]개 추출
생성 완료: [newsletter.csv 전체 경로]
```

### 2단계 진행 및 완료

```text
Photoshop 자동화를 시작합니다. 완료될 때까지 기다리세요.
생성 완료: [결과 PSD 전체 경로]
생성 완료: [전체 뉴스레터 PNG 전체 경로]
```

### 3단계 정상 완료

```text
결과 HTML: [vdi HTML 전체 경로]
링크 적용: 사업안내 [개수], 아카데미 [개수], 배너 [개수]; 기존 링크 유지 [개수]; 수신거부 변경 [개수]
결과 HTML: [mutu24 HTML 전체 경로]
입력 완료: 헤드라인 1, 해외시장뉴스 [개수], 사업안내 [개수], 아카데미 [개수], 배너 3, 경제외교 [개수]
이미지 src: 변경 없음
상단 순서: 사업안내 → 해외시장뉴스 또는 해외시장뉴스 → 사업안내
생성 완료: [vdi HTML 전체 경로]
생성 완료: [mutu24 HTML 전체 경로]
```

### 4단계 정상 완료

```text
반입 ZIP: [ZIP 전체 경로]
```

### 각 단계 검수 화면

```text
============================================================
[검수 필수] [단계명]
============================================================
[ ] 확인 항목

위 항목을 모두 확인한 뒤 Enter를 누르세요:
```

### 경고가 있을 때

```text
경고: [상세 내용]
1단계가 경고와 함께 완료됐습니다. 위 경고를 확인하세요.
3단계가 경고와 함께 완료됐습니다. 위 경고를 확인하세요.
Photoshop 작업에 경고 또는 오류가 있습니다: [로그 전체 경로]
Photoshop 작업은 끝났지만 상태 로그를 확인할 수 없습니다. output 폴더를 확인하세요.
```

### 오류가 있을 때

```text
오류: [상세 내용]
1단계에서 오류가 발생했습니다. 위 메시지를 확인하세요.
newsletter.csv가 없습니다. 먼저 1을 실행하세요.
Photoshop 스크립트가 없습니다: [fill.jsx 전체 경로]
Photoshop 자동화에 실패했습니다: [로그 전체 경로]
수동 복구를 위해 원본 PSD를 열었습니다.
3단계에서 오류가 발생했습니다. 위 메시지를 확인하세요.
4단계에서 오류가 발생했습니다. 위 메시지를 확인하세요.
```

### 잘못된 번호 또는 종료

```text
1, 2, 3, 4 또는 0을 입력하세요.
작업을 종료합니다.
```

```text

Missing folder: [work_history\발행일\input 경로]
Automation stopped with an error.
Press any key to continue . . .
```
